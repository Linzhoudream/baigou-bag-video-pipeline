## 三、同卖点对照：硬广 vs 种草（以"太空舱猫包·通风"为例）

| 表达 | 硬广轴（脚本 C 思路） | 种草轴（本文件思路） |
|------|----------------------|----------------------|
| 开场 | "猫包闷死猫？今天真测给你看"+温度计对比 | "它今天要出远门"（拉链声）/ "带猫出门最怕它应激" |
| 卖点呈现 | 竞品38° vs 太空舱31° 数据打脸 | "进去就不想出来"呼噜声 / "路上它睡着了" |
| 广告感 | 中高（像打假测评） | 极低（像朋友分享） |
| 资产沉淀 | 一次性 | IP/连续剧可续更 |

> 结论：卖点相同，**种草轴把"通风好"从"被证明"变成"被体验"**，广告感更低、完播/收藏预期更高。

## 四、SOP 落点（待写入 Track C 剧本）

### Stage 0 增加「内容模式选择」
在 Stage 0 末尾新增：
> **0.4 内容模式选择**：每条创意先定模式——默认 🟢**种草轴**（ASMR/IP/POV/情感/UGC）；仅在「大促/价格节点/信任背书」切 🔸**硬广轴**（溯源展示/对比平替/痛点实测）。周更中种草轴占比 ≥ 3/5。

### Stage 2 增加「双轴形式清单」
- **种草轴形式清单**：ASMR场景化 / 角色IP连续剧 / POV第一人称 / 情感金句 / UGC仿装 / 互动投票 / 反转 / 软化溯源（故事版）。
- **硬广轴形式清单**：产业带溯源（展示版）/ 对比平替 / 痛点实测 / 极限测试。
- 选题推荐时按所选模式调用对应清单，而非单一排序。

### 任务3 选题模板增加字段
- 新增「内容模式：种草轴 / 硬广轴」
- 新增「广告感强度：极低 / 低 / 中 / 高」
- 强制：种草轴内容占比达标（周更 5 条 ≥ 3 条低广告感）。

## 五、测试验收口径（看效果看什么）

| 指标 | 看什么 | 达标信号 |
|------|--------|---------|
| 完播率 | 种草轴 vs 硬广轴 同期 | 种草轴 ≥ 硬广轴 |

# 箱包视频流水线 · 测款创新轨道（Track B）设计说明

> 背景：v3 现有 8 任务 + 附录五/六是"量产线（Track A）"，优化目标是稳定、合规、品牌一致。
> 问题：流程公开 + 模型趋同 → 产出收敛到"安全均值"，图/视频同质化。
> 思路：**量产 ≠ 测款**。把"创新/测款"拆成独立轨道 Track B，复用同一套 ①~⑥ 库，但目标从"不出错"变成"撞爆点"。

---

## 一、先对齐：这就是多智能体 + 编排者

- 8 个子技能（skill_01~08）= 执行体，各自只懂自己的任务。
- 编排技能（orchestrator）= **掌握全局、把控节点**：持有进度状态、决定下一步、在 4.5 这种质量门处放行或打回、失败时从断点续跑。
- 这是"一般情况下"的标准协同形态，保证可靠，但也正是同质化的来源——可靠 = 收敛到均值。

---

## 二、同质化的根因（不是流程的错，是用法错了）

| 维度 | 为什么会撞脸 |
|------|--------------|
| 流程公开 | v3 的"10 条脚本规则""10 种创意形式"对手可复制 |
| 模型趋同 | 大家都用 seedance/即梦/可灵默认美学，视觉语言撞车 |
| 选题趋同 | 都盯抖音热榜/蝉妈妈，选题池重叠 |
| 求稳心态 | 人审只挑"安全好看"的，反而把有刺点的版本筛掉了 |

> 核心错位：**用量产线的"求稳"逻辑去做测款** → 产出个个安全、个个像。

---

## 三、测款的本质 = 低成本快速试错，不是量产

测款要的是 **variation × speed × cheap**，允许翻车。所以 Track B 与 Track A 是**两个相反目标的轨道**：

| | Track A 量产线（现有 v3） | Track B 测款线（新增） |
|--|--|--|
| 目标 | 稳定、合规、品牌一致 | 找爆点、敢翻车 |
| 数量 | 每日固定产出 | 小批量多变量 |
| 筛选 | 只留"安全好看" | 专门留"有点冒险/不对劲" |
| 回收 | 周度复盘 | 小流量即时回收，爆的转正轨 |

---

## 四、测款线怎么做出差异化（6 个具体杠杆）

### 1. 视觉基因锚定（Style Anchoring）—— 不靠模型默认美学
- 建**专属参考图库 / LoRA**：白沟工厂实拍、特定打光、材质微距，用即梦/seedance 的"参考图控制"出图，而不是纯文生。
- 定一条**反共识审美基线**：别人走亮调 ins 风，你走暗调工业纪实。
- 从 ①情报库 挖"视觉空白点"（竞品没覆盖的画风）。

### 2. 变量化矩阵（A/B/n）—— 把"创意"拆成可变量批量撞
- 变量维度：**钩子类型 × 画风 × 主角（真人/拟人猫/IP角色）× 节奏 × 配音音色**
- 一次出 9~16 个变体 → 小流量测 → 数据回写 ⑥复盘库 → 反哺 ②选题库。
- 直接复用 v3 任务4 做"变量化改写"（同一选题生成 N 个脚本变体）。

### 3. 反共识选题 —— 别人追热榜，你挖"热榜的背面"
- 用 ①情报库"用户吐槽高频痛点"（任务1 维度4）做**反种草**内容。
- 跨境挖 TikTok 小众 niche（老年猫出行包 / 航空合规痛点）。
- **供应链独家视角**（白沟工厂探厂、面料科普）是别人抄不走的壁垒，直接做成差异化母题。

### 4. 叙事结构跨界组合
- v3 任务4 列了 10 种形式，但同质化来自"都选同一种"。测款线**强制跨形式组合**：角色IP×ASMR、纪录片×反转。
- 编排技能加"随机/轮询组合"逻辑，产出非常规结构。

### 5. 工具层指纹
- "模型大同小异"的解法：混用不同模型的**非默认参数、不同 seed、不同参考图**制造风格指纹。
- 故意用非主流组合（即梦出首帧 + 可灵做运动 + 手动合成）做出别人没有的质感。

### 6. 人审的"刺点"机制
- 林舟手动筛时，**专门挑"看起来不对劲/有点冒险"的版本**进测款池，而非只挑安全款。
- 同质化是"求稳"的副作用，测款要奖励冒险。

---

## 五、怎么接回 v3（不破坏量产线，新增 Track B）

复用同一套 ①情报库 / ②选题库 / ③文案脚本库 / ④多平台适配库 / ⑥复盘数据库，只增量改动：

- **任务3** 增加模式：`测款选题`（反共识 / 变量化），不再只出 3 个"安全选题"。
- **任务4** 增加模式：`变量矩阵生成`（一次出 N 个脚本变体，而非 1 条精修）。
- **任务5** 出图强制带**风格参考图**（LoRA / 参考图控制），不再是纯 prompt 文生。
- **新增 任务9 测款回收**：小流量数据回写 ⑥复盘库，爆的升Track A 量产、扑的归档。
- **编排技能**加参数：`mode=produce`（默认量产） / `mode=test`（测款轨道），切换两轨。

> 这样 v3 量产线一行不动，测款能力作为"平行轨道"叠加，互不影响、可随时降级回纯量产。

---

## 六、一句话总结

> 量产线解决"稳定不出错"，测款线解决"怎么不一样"。同质化不是流程的错，是**你用量产线去干测款的活**——给测款单独开一条"敢翻车"的轨道，用「变量矩阵 + 专属视觉基因 + 反共识选题 + 刺点人审」去撞爆点，撞中了再丢回量产线放大。

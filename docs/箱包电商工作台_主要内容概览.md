## 一、一句话总览

这是一套**以「白沟箱包」为产业背景、由「林舟」运营的 AI 内容运营工作台（林舟工作台）**。它把"选题→脚本→出图/视频→多平台分发→复盘"做成了一条**可定时批量自动化的内容生产线**，并配套了"情报 / 信号 / 爆款公式 / 草稿 / 日志"五大知识中枢。

## 三、核心运营管线（来自"定时任务提示词库 v3"）

文档把视频内容生产拆成一条清晰流水线，共 **8 个主任务 + 1 个质检环节**：

1. **每日热点简报** — 汇总当天行业热点
2. **竞品动态监测** — 跟踪竞品动作
3. **每日选题推荐** — 输出当日选题
4. **批量脚本生成** — 按公式批量产出脚本
4.5. **脚本质量审核** — 质检门（数据仪表盘质量门）
5. **帧图生成 + 视频生成** — 出图与 I2V 视频
6. **后期合成** — 剪辑合成
7. **多平台文案适配** — 小红书 / 抖音 / TikTok 差异化
8. **周度数据复盘** — 数据回收与迭代

> 前置依赖：**核心数据源速查表**（国内电商数据平台 / TikTok 跨境数据平台 / 箱包产业&原材料数据 / 跨境合规&政策 / 行业资讯&痛点采集）+ **Phase 2 人工补充数据模板**。
> 配套附录：文件夹结构对应、文件命名规范、任务时间线、降级策略汇总。

## 五、当期内容产出（2026-08-01 主题）

**核心论点**：*「装了一屏 AI 软件还是憋不出标题？你缺的不是 AI 工具，是一条产线。」*

- **主草稿**（草稿中枢）：一篇"对着空白文档俩小时憋不出标题"的痛点文，含四段公式（痛点 / 心法 / 金句 / 三步法）与表格脚本。
- **小红书版**（图文笔记，约 560 字）：8 段结构（发布规格 / 封面文案 / 正文 / AI 标注位 / 检查清单 / 公式应用 / 封面图 prompt / 指纹差异）。
- **抖音版**（9:16 竖屏 40s，保定话口播）：分镜 4 镜（钩子→数据背书→分屏对比→三步法+CTA），附分镜图 prompt ×4。
- 两版均强调 **"只产出文字、绝不自动出图"**，由林舟筛选后自行丢即梦生成，以规避限流与风格失控。

## 六、资源与分工（外部资源总表 v2）

- **AI 负责**：定期追踪的情报、随时可查的网站（已逐站实测 2026-07-25）、按需查询工具
- **林舟负责**：封闭渠道平台（AI 进不去）、需手动补充内容、书籍
- **痛点挖掘分工**：🟢 先做（零社交低精力高原创）→ 🟡 可做（零社交中精力）→ 🔴 后做（需社交暂不做）
- 含：情报追踪关键词、快速对照表、产业数据校准记录、AI 可查性实测记录

## 七、我的判断

1. **这是一套成熟度很高的内容工业化系统**：不是"用 AI 写文案"的零散玩法，而是把选题—脚本—视觉—分发—复盘做成带质检门和降级策略的标准管线。
2. **"产线 > 工具"是贯穿全局的叙事主线**：既是当期内容主题，也是整套工作台的设计哲学。
3. **人机分工清晰**：AI 做情报/批量/适配，人做封闭渠道与最终审美把关（出图不自动跑）。
4. **待补盲点**：核心资产包（aio）与出图+I2V 模板库的正文因权限未能读取，如需深挖这两份，建议先在浏览器登录腾讯文档后再让我抓取。

# Track C 每日自动产出剧本（SOP）

> 用途：把"升级版 Track C 内容流水线"固化成一份可每日复跑的剧本。本环境用 `automation-task-manager` 技能（底层 `scheduler-api.sh`）挂每日定时任务；无任务时用户发下方【触发词】也可手动跑。
> 核心原则：**图片不自动生，先出提示词+建议，人挑了再出图**（省额度、保选择权）。
> 完整链路：**情报层（市场需求挖掘 → 趋势分析）→ 对标拆解 → 创意设计 → 图像提示词 → 种草脚本**。本 SOP 覆盖全链路，不只创意段。
> 关联正本：方法文档 `{{DOC_METHODOLOGY_FILE_ID}}`、Track C 母文档 `20260803-TrackC再跑-升级版.md`、去广告化重写 `20260803-种草文案去广告化重写.md`、爆款研究见 `20260803-种草文案去广告化重写.md`。

## 一、每日流水线（全链路，按序执行）

### Stage 0 · 情报层（市场需求挖掘 + 趋势分析）【轻量，每日必做】
目的：让当日创意有真实市场信号支撑，而非凭空拍脑袋。
1. **市场需求挖掘**：做 2–3 次定向 WebSearch，覆盖：
   - 包挂 / bag charm / 毛绒挂件 的当下趋势与平台热度（小红书、TikTok、抖音）；
   - 情绪经济 / 陪伴经济 / 孤独经济 消费动向；
   - 对标品类或原料端信号（如 Labubu/Jellycat 价盘、白沟双产业带政策/出海/数据）。
2. **趋势分析**：把检索结果收敛成 **1–2 条"今日主趋势"**（带来源链接），例如"18+ 成年人包挂增长最快""情价比取代性价比"。
3. 输出：情报小节（信号 + 来源 + 一句趋势判断）。
4. **内容模式选择（2026-08-04 起）**：每条创意先定模式——
   - 🟢 **种草轴（默认）**：创新种草 + 弱化产品广告，形式含 ASMR场景化 / 角色IP连续剧 / POV第一人称 / 情感金句 / UGC仿装 / 互动投票 / 反转 / 软化溯源（故事版）。**测试期统一用此轴**，观察完播/收藏/商品点击。
   - 🔸 **硬广轴（兜底）**：产品导向、广告感高，形式含 产业带溯源(展示版) / 对比平替 / 痛点实测 / 极限测试。仅在大促、价格节点、信任背书场景切入。
   - **占比规则**：周更中种草轴占比 ≥ 3/5；任务3 选题须标「内容模式」与「广告感强度」字段。

### Stage 1 · 对标拆解（每日 1 个样本）
目的：从已验证的爆款里拆出可迁移的结构手法，避免创意自嗨。
1. 选 1 个对标样本：近期一条爆款笔记 / 竞品打法 / 对标账号的某条内容（可从 Stage 0 检索顺藤摸到，或指定赛道）。
2. 拆解其结构：**钩子类型（结果/痛点/悬念/冲突/共鸣）· 转折手法 · 完播技巧 · 评论区情绪 · 为什么火**。
3. 提炼 **1 条可迁移手法**，用于当日脚本（如"用'你有没有过…'戳具体场景""结尾抛开放问句拉评论"）。
4. 输出：对标小节（样本 + 结构拆解 + 可迁移手法）。

### Stage 2 · 创意设计（基于 Stage 0+1）
1. **当日主题**：按错峰方向表（日%5）取 1–2 个创意方向组合，并用 Stage 0 的"今日主趋势"做约束（如趋势偏"情绪急救"则优先 C1/C5）。
2. 五方向库：
   - C1 情绪急救包（包=情绪外显，砍"装东西"约束）
   - C2 可生长陪伴系统（单元从单品→关系系统）
   - C3 身份切换胶囊（稳定载体×流动身份）
   - C4 全家福共生体（包×宠物×挂件三件套同源）
   - C5 夜归安全灯挂（情感×功能，内置暖光 LED）
3. **内容模式 × 形式清单（2026-08-04 起）**：按 Stage 0 选定的模式，调用对应形式清单生成选题——
   - 🟢 **种草轴形式清单**（默认）：ASMR场景化 / 角色IP连续剧 / POV第一人称 / 情感金句 / UGC仿装 / 互动投票 / 反转 / 软化溯源(故事版)。卖点"埋"进内容，不叫卖。
   - 🔸 **硬广轴形式清单**（兜底）：产业带溯源(展示版) / 对比平替 / 痛点实测 / 极限测试。直接展示产品力/价格/参数。
   - 任务3 选题须带「内容模式」与「广告感强度：极低/低/中/高」字段；周更 5 条中 ≥3 条须为低广告感（种草轴）形式。

### Stage 3 · 图像提示词（6 条）
每条含【编号 / 对应方向 / 分镜类型 / 风格 / 完整英文 ImageGen 提示词 / 适配脚本结构】。分镜覆盖：产品图、flatlay、生活场景、微距细节、夜景氛围、全家福/宠物、换装过程（至少 4 类）。

### Stage 4 · 种草脚本（2–3 条）
套用已验证结构（故事/痛点/悬念/反差/盘点/情绪共鸣），**融入 Stage 1 的可迁移手法**与 Stage 0 的趋势信号。第一人称、品牌虚指或隐去、零 CTA、结尾开放问句。每条带【结构 / 3秒钩子 / 口播 / 字幕轴 / 配图编号】。

### Stage 5 · 产出与归档
1. 写入 `/workspace/自动产出/TrackC_auto_YYYYMMDD.md`（含情报小节 + 对标小节 + 6 提示词 + ★推荐 + 脚本）。
2. ★推荐 2–3 条 + 理由；其余标"备选"。
3. 登记进 `/workspace/腾讯文档备份索引.md`（本地测试产物区 + 本次更新注记）。
4. 尝试腾讯文档备份（写工具不可用则标"待补"）。
5. 结尾列出 ★ 编号与提示词，注明"回复编号即可出图"。

### Stage 6 · 可信度门（防信息污染，每日必过）
目的：每日产出的内容若不经核实就看起来"权威"，正是信息污染放大器；故每条输出须自带可信度标注。
1. **分级标注**：原理层可直述；命名机制 / 平台 / 政策类须附来源链接；具体数字 / 日期 / 统计 / 引用、因果"%"断言、2026 专属产品 / 保险 / 工具的存在性断言，一律标【待验证】。
2. **种草脚本护栏**：脚本若引用任何未验证事实（如"某趋势增长 X%"），须显式标注为假设，不得当既定事实陈述给观众。
3. **本周待验证清单**：文末额外输出一段"本周待验证清单"，累加本批次所有【待验证】项（含来源 / 断言内容），供「每周深度情报任务」统一核验销账。
4. 自检：本批次是否还有"听起来对但无来源"的断言？有则补【待验证】。

## 二、去广告化硬规则（每条成片前自检）
- [ ] 删掉所有"因为…所以好""不是装饰是…"这类卖家结论句
- [ ] 品牌虚指或隐去（不写具体品牌/店铺，让人评论区问）
- [ ] 用真实人物关系（闺蜜/我妈/同事），不用泛"朋友"
- [ ] 痛点具体到时间/地点/数字
- [ ] 结尾是问句/开放观察，不是"点击购买/看主页"
- [ ] 产品是"被发现"的细节，不是"被介绍"的主角

## 三、图片生成门控（关键）
- 每日批次**只产出提示词与建议，不调用 ImageGen**。
- 用户回复所选编号 → 才对选中项调用 ImageGen（quality high，尺寸按分镜：竖版 1024x1536 / 横版 1536x1024），存入 `/workspace/TrackC_concept_images/` 或当日子目录。
- 若用户说"全出"，则对全部 ★ + 备选分批生成（注意额度）。

## 四、本地登记 + 云端备份
- 每次运行后，在 `/workspace/腾讯文档备份索引.md` 的"本地测试产物"区补一行（批次文件 + 一句话说明），并在"本次更新注记"加一条。
- 尝试腾讯文档备份（追加进方法文档 `{{DOC_METHODOLOGY_FILE_ID}}` 或新建 Track C 专文档）；若写工具不可用，标"腾讯同步待补"。

## 五、可选：每周深度情报任务（ heavier）
每日 Stage 0 是轻量扫描；如需更厚实的「市场需求 + 趋势 + 对标」月度库，可另挂一个 **weekly** 任务（frequency-type=interval 或每周一），产出 `/workspace/自动产出/情报周报_YYYYMMDD.md`（多源检索 + 3–5 个深拆对标 + 趋势研判），供每日任务引用。是否挂由用户决定。

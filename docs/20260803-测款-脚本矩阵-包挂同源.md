# 20260803-测款-脚本矩阵·包挂同源套装（Track B · task04_test）

> 来源方向：裁决①选中「包挂同源套装」(v2.1 方向①，白沟双产业护城河种子 / Track C 苗头)
> 方向内核：白沟同时拥有**箱包 + 毛绒玩具**两条产线，能出品"包与挂件同源设计、可换肤配套"的套装——别处只能做其一，讲不出"同根"故事。叙事语法走 萌 / 收藏 / 社交货币 / 身份 / 开箱 / 改妆，吃潮玩流量池。
> 产出：6 条变量脚本（钩子×画风×主角×节奏×音色），存 ③文案脚本库，标记 `测试`。
> 注：每条 20–30s，前 3 秒强钩子，台词字数匹配口播节奏；画风/主角/结构允许突破量产默认。

## 变体A ｜ 【冲突钩子·实拍混剪·工厂师傅·快剪·保定方言】

- **3秒钩子**：「你花 199 买的潮玩包，挂件是后配的凑数货；白沟源头，包和挂件是一个妈生的。」
- **钩子类型**：冲突（同源 vs 后配）
- **画风**：实拍混剪（工厂两条产线同框：裁包车间 + 充棉车间）
- **主角**：工厂师傅（手持包+同款毛绒挂件，指"同一版师出的"）
- **节奏**：快剪（0.8s/镜，车间走位+特写拼接）
- **音色**：保定方言（接地气、可信源头感）
- **核心角度**：同源基因——版师同一套设计语言，包与挂件共享花纹/配色/IP，可整套换肤
- **推荐视频形式**：探厂混剪 + 同源对比特写
- **时长/台词**：22s｜口播≈90字
- **适配平台**：抖音 / 视频号

## 变体B ｜ 【反差钩子·亮调ins·拟人猫·慢叙事·萌系猫叫】

- **3秒钩子**：「别人的包挂是装饰，白沟的包挂有'户口本'——它和包是亲生的。」
- **钩子类型**：反差（装饰 vs 血亲）
- **画风**：亮调 ins（柔光、马卡龙背景、产品静物感）
- **主角**：拟人猫（第一人称 POV，猫爪扒拉挂件"这是我哥"）
- **节奏**：慢叙事（1.5s/镜，配轻音乐）
- **音色**：萌系猫叫 + 字幕旁白
- **核心角度**：可换肤套装——一套出 3 种配色，包和挂件同步换"皮肤"，社交平台晒图即内容
- **推荐视频形式**：开箱 + 换肤演示（慢镜头）
- **时长/台词**：26s｜旁白≈70字 + 猫叫拟声
- **适配平台**：小红书 / 抖音

## 变体E ｜ 【疑问钩子·ASMR·真人·ASMR·知性女声】

- **3秒钩子**：「你的包和挂件，真的是'一套'吗？拆给你看。」
- **钩子类型**：疑问（同源验证）
- **画风**：ASMR 特写（微距、无 BGM、环境收音）
- **主角**：真人手部出镜（拆套装、对纹样、换肤）

- **核心角度**：可验证同源——花纹对得上、磁吸接口同源、换肤不违和，肉眼可证"不是后配"
- **推荐视频形式**：ASMR 开箱 + 同源对版
- **时长/台词**：25s｜轻声旁白≈60字
- **适配平台**：抖音 / 小红书（ASMR 流量友好）

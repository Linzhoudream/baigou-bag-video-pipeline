## 二、任务3 · 每日选题推荐（种草轴 · 5 选）

> 账号定位：白沟源头箱包商家｜受众：①国内通勤上班族/养猫铲屎官 ②跨境小卖家/批发商
> **本轴关键字**：弱化广告感、靠体验/情绪/人设种草。

### 选题 1【ASMR 场景化】— 沉浸体验
- **3秒钩子（画面+字幕）**："它今天要出远门"（拉链特写+沙沙声）
- **适配受众**：国内铲屎官
- **核心角度**：开箱猫包的沉浸声音体验，零叫卖
- **视频形式**：ASMR
- **完播风险**：无台词易平淡 → 靠声音层次+猫反应吊住

### 选题 2【角色 IP 连续剧】— 拟人化
- **3秒钩子**："本喵的出行装备，升级了"（猫主角拟人配音）
- **适配受众**：国内 + 跨境（猫视角）
- **核心角度**：猫第一人称连续剧，沉淀 IP
- **视频形式**：角色 IP 连续剧
- **完播风险**：首集需立住人设 → 固定开场 BGM + 猫设

### 选题 3【POV 第一人称】— 情景
- **3秒钩子**："带猫出门最怕它应激"
- **适配受众**：国内铲屎官
- **核心角度**：带猫出门 vlog，自然带出通风舒适
- **视频形式**：POV 第一人称 / 情景
- **完播风险**：无强冲突 → 靠"睡着/不挣扎"的反差钩子

### 选题 4【情感金句】— 情绪共鸣
- **3秒钩子**："养猫后才懂，它愿意跟你出门是信任"
- **适配受众**：国内铲屎官
- **核心角度**：情绪价值前置，卖点退为背景
- **视频形式**：情感金句
- **完播风险**：易变鸡汤 → 配具体场景不空泛

### 选题 5【UGC 仿装 + 软化溯源】— 互动 + 故事
- **3秒钩子**："你们家猫最想去的地方是？"（评论区互动）
- **适配受众**：国内 + 跨境
- **核心角度**：评论区许愿 + 白沟老师傅做包故事（软化溯源）
- **视频形式**：UGC 仿装 / 互动投票 + 软化纪录片
- **完播风险**：互动引流需强钩子 → 用"替它许愿"参与感兜底

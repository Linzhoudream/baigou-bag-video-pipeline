## 二、任务3 · 每日选题推荐（按优先级 5 选）

> 账号定位：白沟源头箱包商家｜受众：①国内通勤上班族/养猫铲屎官 ②跨境小卖家/批发商

### 选题 1【优先级① 产业带溯源】— 纪录片
- **3秒钩子**："你背的猫包，可能就产自这条 200 米的巷子"
- **适配受众**：国内 + 跨境
- **核心角度**：走进白沟工厂，从布料到成品的全链路（供应链独家）
- **视频形式**：纪录片
- **完播风险**：中段工厂镜头易平淡 → 用"打样第几次/成本揭秘"维持好奇

### 选题 2【优先级② 对比 / 平替】— 对比
- **3秒钩子**："同版型托特，专柜 2999，白沟厂里多少？"
- **适配受众**：国内 + 跨境批发
- **核心角度**：同源皮料五金价格拆解（收藏价值高）
- **视频形式**：对比（分屏）
- **完播风险**：价格揭晓前易划走 → 前 3 秒直接抛悬念数字

### 选题 3【优先级③ 痛点还原 / 解决方案】— POV 实测
- **3秒钩子**："猫包闷死猫？今天真测给你看"
- **适配受众**：国内铲屎官
- **核心角度**：通风实测对比（竞品闷包 vs 太空舱 9 孔）
- **视频形式**：POV 第一人称 / 实测
- **完播风险**：测温等待段易流失 → 用倒计时+读数悬念吊住

### 选题 4【优先级④ 场景化种草】— ASMR / 情景
- **3秒钩子**："早八打工人的通勤包，第 3 样我真离不开"
- **适配受众**：国内上班族
- **核心角度**：通勤场景装载演示（容量+分区）
- **视频形式**：ASMR / 情景喜剧
- **完播风险**：无强冲突 → 靠"第3样"悬念钩子兜底

### 选题 5【优先级⑤ 产品拟人化 / IP 连续剧】— 角色 IP
- **3秒钩子**："我是只爱出门的猫，这是我的专属座驾"
- **适配受众**：国内 + 跨境（猫视角拟人配音）
- **核心角度**：猫的第一人称 vlog，连续剧化沉淀 IP
- **视频形式**：角色 IP 连续剧
- **完播风险**：首集需立住人设 → 用稳定猫设+固定开场 BGM

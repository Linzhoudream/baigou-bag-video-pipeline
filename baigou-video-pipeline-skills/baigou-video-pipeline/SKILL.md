# 箱包视频流水线 · 编排技能（Orchestrator）

你是该流水线的总调度：持有全局状态、按相位推进、在质量门处放行或打回、失败时从断点续跑。**这是多智能体协同的"编排智能体"——掌握全局、把控节点。**

## 参数
- `mode=produce`（默认）：走 Track A 量产线，稳定产出每日内容。
- `mode=test`：走 Track B 测款线，小批量多变量撞爆点。
- `--date YYYYMMDD`：指定日期，默认今天。
- `--resume --from 任务N`：从指定任务续跑，复用已生成的 ①②③ 库，不重做前置。

## Track A · produce 时序（一般情况下的流程）
```
08:00  任务1+2 → 写①情报库
08:30  暂停，提醒运营补付费平台数据进 ①/补充数据
09:30  任务3 → 写②选题库
10:00  任务4 → 写③文案脚本库
10:30  任务4.5 审核（任一❌即停，等人工确认"通过"）
11:00  任务5/6：只产出文字 prompt 给即梦/seedance，人工执行
14:00  任务7 → 写④多平台适配库
周一09:00 任务8 → 写⑥复盘数据库
```

## Track B · test 时序（mode=test，创新测款 · 信号驱动 + 人在回路）

> 方向来自①情报库市场信号（事件/潮流/媒体），不是人拍脑袋；人只在两处收口做轻裁决。

```
task03_test  变量化反共识选题（信号驱动：读①情报库热点，出 N 方向）
   ↓ 【裁决检查点①】你选 2–3 个展开（选+校准+体感否<6 毙）
task04_test  变量矩阵脚本（钩子×画风×主角×节奏×音色，一次 N 变体）
task05_test  风格锚定出图（带参考图/LoRA，非纯文生）
   ↓ 【裁决检查点②】你从测款包里挑哪些真去小流量测（选/融合/推翻）
→ 产出"测款包"交小流量测试
task09_test  测款回收（数据 + 体感双否决，爆的升 Track A 量产，扑的归档）
```

## 定时调度（cron / 半自动）

> 流水线**半自动**运行：AI 自动完成"情报→选题→脚本→首帧/视频提示词→多平台文案→周复盘"的全部**文本产出**，但在几处**人工收口点自动停住**，等运营点"通过"/补数据/做裁决后再继续。真实出图出视频（task05 丢给 seedance/即梦）始终是人工动作，不在自动范围内。

### 自动段（可定时跑，无需人）
| 时间 | 任务 | 写入库 | 说明 |
|------|------|--------|------|
| 每日 08:00 | task1+2 热点+竞品 | ①情报库 | 公开源检索，缺付费数据自动降级标 ⚠️ |
| 每日 09:30 | task3 选题 | ②选题库 | 读①+补充数据 |
| 每日 10:00 | task4 脚本 | ③文案脚本库 | 每选题 1 条 |
| 每日 11:00 | task5/6 首帧+视频提示词 | 素材库 | **仅文字 prompt**，人工执行渲染 |
| 每日 14:00 | task7 多平台文案 | ④多平台适配库 | 4 平台 × N 脚本 |
| 周一 09:00 | task8 周复盘 | ⑥复盘数据库 | |

### 人工收口点（自动段在此停等，不跳过）
- **08:30 补数据**：task1+2 跑完后暂停，运营把蝉妈妈/飞瓜/竞品投放截图塞进①「补充数据」，再放行进 task3。
- **10:30 质量门 4.5**：脚本审核任一 ❌ 即停，输出修改建议，等人工"通过"才放行进 task5。
- **Track B 裁决①/②**：测款方向池（6~9）收口选 2~3；测款包挑哪些真去小流量测。体感否决（<6 分）无需数据即可毙。
- **渲染**：task5 产出 prompt 后，真出图/出视频由人工在 seedance/即梦 完成。

### crontab 规格
见同目录 `cron_schedule.txt`（含完整条目与 gate 注释）。安装：`crontab cron_schedule.txt`。
> 注：本沙箱/当前环境无 headless 执行器，cron 仅作为**调度规格**落档；真正触发需平台侧"定时运行技能"能力或把 `dispatch.sh` 接到编排智能体。人工收口点不会被定时跳过。

## 节点把控（关键）
- **4.5 审核任一❌**：停止后续，输出修改建议，等人工确认"通过"方可继续。
- **降级**：数据源缺失自动降级并标 ⚠️，不阻塞主流程；行业基准缺失标「⚠️ 缺行业基准数据」。
- **状态**：每次动作后更新 state 文件（当前阶段 / 各库最新文件 / 待办），供 `--resume` 使用。
- **同质化防御**：Track B 的作业目标与 Track A 相反——允许翻车、奖励"刺点"，不要用量产线的"求稳"逻辑筛测款。

# 白沟箱包短视频 · AI 内容流水线（开源技能包 + 方法论）

> 一套面向**箱包 / 产业带短视频**的 AI 内容生产流水线：用「双轨 + 双轴」架构，把**量产（稳产出）**与**测款（撞爆点）**分开跑，配合「人在回路」的轻裁决，自动化产出短视频脚本、分镜提示词与多平台文案。
>
> 本仓库是**脱敏公开版**：已剔除所有私有腾讯文档 `file_id` 指针与运行态数据，可作为开源项目直接使用或二次开发。

---

## 一、核心架构（理解这套东西先读这段）

### 双轨（宪法级命名）
| 轨 | 角色 | 命名 | 目标 |
|----|------|------|------|
| **Track A 量产线** | 编码 | 编码 = Track A | 每日稳产出、合规、品牌一致 |
| **Track B 测款线** | 留白 | 留白 = Track B | 小流量撞爆点、允许翻车 |

> 同质化不是流程的错，是**用量产线去干测款的活**。测款单独开一条「敢翻车」的轨道。

### 双轴（默认种草轴）
| 轴 | 目标 | 广告感 | 占比 |
|----|------|--------|------|
| 🟢 种草轴（默认） | 养粉、拿完播/收藏、长期 IP | 低 | 周更 ≥ 3/5 |
| 🔸 硬广轴（兜底） | 快速转化、信任背书 | 高 | 节点性启用 |

### 创意公式
> **新创造 = 外生信号 × 跨域语法重组 × 供应链壁垒 × 人在回路裁决**

### 需求溯源组合格
> **品类 = L1(携带物) × L2(场景) × L3(人群) × L4(痛点)**

以「白沟箱包产业带」为案例背景：在 L1「情感陪伴物」维度，产业带可同时做「包 + 毛绒」并讲「包挂同源配套」，形成组合优势。（注：本仓库保留白沟作为教学案例，相关商业断言已泛化。）

## 三、快速开始

1. **读架构**：先看 `综合提示词库v4-公开版.md` 的「〇、总架构」Section，把双轨/双轴/创意公式钉死。
2. **用技能包**：`skills/` 下的 SKILL.md 是给 Agent / 编排器调用的技能定义。编排智能体 `baigou-video-pipeline` 支持 `mode=produce`（Track A）/ `mode=test`（Track B），并带 `dispatch.sh` + `cron_schedule.txt` 半自动调度规格。
3. **跑样例**：`examples/` 是脱敏后的真实产出（种草轴 / 硬广轴 / 包挂+双肩包组合），照着改品类即可复用到你的赛道。

## 四、重要声明（使用本仓库前必读）

- **`file_id` 占位符需回填**：源码中 `{{TENCENT_DOC_V3_FILE_ID}}`、`{{KB_INTEL_FILE_ID}}` 等是脱敏占位符。若要接回腾讯文档知识库，请自建对应文档并把 file_id 填回各 `skills/**/SKILL.md` 与 `综合提示词库v4-公开版.md`。不使用知识库时，可改为本地 Markdown 文件读写。
- **出图/出视频需人审 + 外部工具**：本流水线严守「只出 prompt，绝不自动出图」，首帧/分镜需人工在即梦 / seedance / 剪映 等执行。
- **「白沟」为公开产业带案例**：作为教学背景保留，相关排他性商业断言已泛化，不构成任何独家数据披露。
- **未包含的内容**：私有腾讯文档索引、战略/护城河/竞争分析类内部文档、AI 生成概念图（含未发布产品方向）**未纳入本公开版**，如需请单独评估。
